# Django React JWT

A full-stack complete authentication with django , django rest framework and react js

[![My Skills](https://skillicons.dev/icons?i=python,django,sqlite,html,css,js,ts,react,tailwind)](https://github.com/hosseinyn)


### Features : 
1- Login

2- Signup

3- Change password

4- Delete account

5- Manage jwt access tokens and refresh tokens


### How to use?
1- Clone the repository : 

`git clone https://github.com/hosseinyn/django-react-jwt.git`

2- Open project directory

`cd django-react-jwt`

3- Open backend directory

`cd backend`

4- Install dependencies

`pip3 install -r requirements.txt`

5- Run backend

`python manage.py runserver`

6- Open frontend directory

`cd frontend`

7- Install frontend dependencies

`npm install`

8- Run frontend

`npm run dev`
